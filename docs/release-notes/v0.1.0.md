## TextRepairo 0.1.0

Write it right: paste messy text in any language, get clear English back. Runs fully on your computer after a one-time model download.

### Downloads

| System | File |
|---|---|
| Windows 10/11 | `TextRepairo-Setup-0.1.0.exe` (installer) or `TextRepairo-0.1.0-windows-x64.zip` (portable) |
| macOS (Apple Silicon) | `TextRepairo-0.1.0-macos-arm64.dmg` |
| Linux (x64) | `.AppImage`, `.deb` or `.tar.gz` |

Verify downloads with `SHA256SUMS.txt`.

### Highlights

- Styles: **Fix**, **Formal**, **Friendly**, **Prompt**. Any language in, English out.
- Local Qwen3 models (Apache-2.0): Lite 1.7B, Standard 4B (recommended), Pro 8B. Import your own `.gguf` too.
- Changes view, warnings, protected links and code, copy and retry.
- Desktop app, web UI (`textrepairo serve`) and CLI (`textrepairo repair ...`).
- Private by design: loopback-only, token protected, no telemetry. Low priority and about half the CPU cores by default so the PC stays cool.

### Good to know

- First start: Windows may show a SmartScreen notice, *More info > Run anyway*. macOS: right-click the app > *Open*, or `xattr -cr /Applications/TextRepairo.app`.
- On Linux the app opens in your browser (a native window needs extra system libraries).
- Small models can occasionally rephrase too much. Check the *Changes* tab before you copy important text.
