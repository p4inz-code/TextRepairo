## TextRepairo 0.2.0

**Smarter, safer, and written to sound like a person.** Paste messy text in any language, get clear, natural English back. It runs on your computer.

### Downloads

| System | File |
|---|---|
| Windows 10/11 | `TextRepairo-Setup-0.2.0.exe` (installs for your user, can update itself) |
| Windows 10/11, portable | `TextRepairo-0.2.0-windows-x64-portable.zip` (keeps everything in the `data` folder next to the app) |
| macOS (Apple Silicon) | `TextRepairo-0.2.0-macos-arm64.dmg` |
| Linux (x64) | `.AppImage`, `.deb` or `.tar.gz` (the `.tar.gz` is portable) |

Verify downloads with `SHA256SUMS.txt`. Releases also include a software bill of materials (`...-sbom.cdx.json`) and a build attestation (`gh attestation verify <file> --repo p4inz-code/TextRepairo`).

### What is new

- **A real progress bar.** Real percentage, part number, speed and time left. Reading uses the engine's own counters. Writing is an estimate and never shows 100% early. Loading the model shows seconds, not a made-up percentage.
- **Eleven styles and three formality levels.** Fix, Professional, Friendly, Prompt, Compose, Message, Email, Casual, Concise, Persuasive, Empathetic. Formality: Normal, Advanced, Extremely formal.
- **Natural by default.** Every style follows "write like a person" rules and drops stock AI phrases you did not write.
- **Compose.** Turn scattered notes into a finished message, prompt or structured prompt. It never invents facts.
- **Slang packs.** English chat shorthand and slang, Hindi/Hinglish and Marathi typed in English letters. Add your own.
- **History** of your last 100 results, on your computer only, with Private mode, Forget on exit and delete controls.
- **Doctor and About** inside the app. Doctor checks the engine, the model checksum, your data folder and that nothing is reachable from the network.
- **Portable mode**, **optional auto-update** (Automatic, Notify me or Off), a **10,000 character** limit with a live counter, and a much improved **command line**.
- **Every control is custom drawn** and keyboard operable: dropdowns, switches, dialogs, drawers, tooltips, context menus and scrollbars.
- **Safer:** session cookie instead of a token in the address, strict content security policy, origin checks, pinned checksums for the downloaded engine, CI dependency audit and CodeQL.
- Phone numbers, dates and times are now protected like links and code, so the model cannot alter them.

### Good to know

- **Output is English only.** Hindi, Marathi and Hinglish output are planned next (see the roadmap).
- **The Windows installer is now per user.** If you installed 0.1.0 for all users, uninstall it first (Settings > Apps), then install 0.2.0. Your models and settings are kept.
- First start: Windows may show a SmartScreen notice (*More info > Run anyway*). On macOS right-click the app > *Open*, or run `xattr -cr /Applications/TextRepairo.app`.
- The macOS and Linux builds are built and smoke-tested by CI but I have not run them on real machines yet.
- A model can still rephrase more than you want. Check the *Changes* tab before you copy important text.
- The only network use is the optional update check and downloads you start yourself. See PRIVACY.md.
