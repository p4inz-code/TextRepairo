## TextRepairo 0.2.1

A security hardening update. Same downloads as 0.2.0 (installer, portable zip, macOS, Linux), same features.

- **No internal details reach the page.** Errors shown in the app are either written by the app (your home and data folders hidden) or a short generic sentence. Exception text and private paths are never sent to the browser.
- **Safer file picking** for models and slang packs: full path, ordinary file, right type, no network shares, clean saved names, and packs are saved as the app's own validated copy.
- **Pack removal** can only touch files in the packs folder.
- All open code-scanning alerts are resolved. Secret scanning with push protection, private vulnerability reporting and Dependabot alerts are on.

Update from inside the app (Automatic or *Settings > Updates > Check now*) or download from this page. Verify with `SHA256SUMS.txt`.

Details: [CHANGELOG](https://github.com/p4inz-code/TextRepairo/blob/main/CHANGELOG.md), [SECURITY](https://github.com/p4inz-code/TextRepairo/blob/main/SECURITY.md).
