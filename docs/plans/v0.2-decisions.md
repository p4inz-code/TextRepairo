# v0.2 decisions log

Decisions taken during the build that the plan did not cover. Each one is the most reversible, privacy-preserving option. They are repeated under "Needs your decision" in the final report.

| # | Decision | Reason |
|---|---|---|
| 1 | Custom Windows title bar was **not shipped**. | The plan says to keep it only if drag, resize, snap and maximize all work on Windows 11. Those are operating-system behaviors that cannot be verified from this build environment, so the normal title bar stays. Everything else (dropdowns, dialogs, scrollbars, tooltips, menus, switches) is custom. |
| 2 | The Windows installer now installs **per user** (no administrator prompt). | Silent self-updates must not trigger an administrator prompt. Anyone who installed v0.1 for all users should uninstall it first, or install v0.2 once by hand. Noted in the release notes. |
| 3 | The Windows zip is renamed `TextRepairo-<version>-windows-x64-portable.zip` and ships with `portable.flag`. | Makes the portable build obvious. The installer build never carries the flag. |
| 4 | Engine started with `-b 128 -ub 128`. | Lets llama-server report real reading progress every 128 tokens. Same speed, shorter CPU bursts. |
| 5 | Reading phase gets 20 percent of each chunk's bar, writing 80 percent. | Reading cost varies a lot (a cold start reads about 800 tokens, a cached one almost none), so the split is a display choice. The time-left estimate is measured, not derived from the split. |
| 6 | Slang pack seed lists are original work and must be reviewed by a native speaker. | The plan said the user reviews Hindi and Marathi entries after they are in. They are marked as seed lists. |
| 7 | A Doctor "engine test" reports overall speed (tokens over total seconds, including reading). | A short test cannot separate reading from writing reliably. Labelled as a rough speed. |
